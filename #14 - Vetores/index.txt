Anotações – Aula sobre Arrays
Variáveis Compostas (Parte 1)
Variáveis Simples

Cada variável armazena um único valor.

var
    n1: inteiro
    n2, n3, n4: inteiro

inicio
    n1 <- 3
    n2 <- 5
    n3 <- 1
    n4 <- 0
fim

Variáveis Compostas Homogêneas

Armazenam vários valores do mesmo tipo em uma única estrutura.

var
    n: vetor[1..4] de inteiro

inicio
    n[1] <- 3
    n[2] <- 5
    n[3] <- 1
    n[4] <- 0
fim

Variáveis Compostas Homogêneas Unidimensionais (Vetores)

Uso de laço de repetição para leitura dos valores.

var
    n: vetor[1..4] de inteiro
    i: inteiro

inicio
    para i <- 1 ate 4 faca
        leia(n[i])
    fimpara
fim
