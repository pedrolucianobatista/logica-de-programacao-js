# Curso de Lógica de Programação - JavaScript

Repositório com exercícios, práticas e anotações desenvolvidos durante o curso de Lógica de Programação do canal **Curso em Vídeo**, utilizando JavaScript no ambiente Node.js.

O objetivo deste repositório é consolidar fundamentos de lógica e construir base sólida para evolução em desenvolvimento backend.

---

## Tecnologias utilizadas

- JavaScript
- Node.js
- prompt-sync
- VS Code

---

## Estrutura do Repositório

O curso foi organizado por módulos numerados, acompanhando a progressão dos conteúdos:

#01 - Introdução a algoritmos
#02 - Primeiro Algoritmo
#03 - Comando de Entrada e Saída
#04 - Operadores Lógicos e Relacionais

#07 - Estruturas Condicionais 1

#14 - Vetores

Cada pasta contém exercícios práticos (`ex01.js`, `ex02.js`, etc.) e arquivos de apoio quando necessário.

## Conceitos praticados

Durante o curso foram trabalhados:

- ✔️ Variáveis e tipos de dados
- ✔️ Operadores aritméticos e lógicos
- ✔️ Estruturas condicionais (`if`, `else`)
- ✔️ Estruturas de repetição (`for`, `while`)
- ✔️ Procedimentos
- ✔️ Funções
- ✔️ Arrays (Vetores)
- ✔️ Matrizes (arrays bidimensionais)
- ✔️ Entrada de dados via terminal
